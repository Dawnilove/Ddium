# 사용 설명서

PLC(래더)를 배우는 프로그램입니다. 가상 PLC 와 가상 설비(실린더 등)로 연습하고, 학습 미션으로 채점하며, AI 도우미에게 물어볼 수 있습니다. 미쓰비시 GX Works2 의 방식(명령어·스텝·목록 CSV·.gxw)과 호환됩니다.

**처음이면 1장부터, 막혔으면 10장(문제 해결)을 보세요.**

## 1. 빠른 시작 (처음 한 번)
처음 실행하면 **빠른 시작** 카드가 뜹니다. ([? 도움말 → 빠른 시작 보기]로 다시 볼 수 있습니다)
1. 위쪽 실행 막대의 **▶ RUN** 을 누릅니다. (STOP 이면 입력을 눌러도 처리되지 않습니다)
2. 래더 왼쪽 위의 **[모니터]** 를 켭니다. 신호가 흐르는 길이 주황색으로 보입니다.
3. 화면 아래 **PB1** 을 눌러 봅니다. 기본 프로그램은 PB1(X15)로 램프(Y20)를 켜고 PB2(X16)로 끕니다.

## 2. 화면 구성
| 영역 | 설명 |
|---|---|
| 맨 위 | 파일 메뉴·저장, 화면 탭(편집·실습 / 학습 미션), 프로젝트 이름, [▦ 패널], [? 도움말], [⚙ 설정] |
| 실행 막대 | ▶ RUN / ■ STOP, 1스캔, 초기화, 배속(0.1×~5×), 가상 PLC · PLC 실행 · 앱 구동 |
| 편집기 | 래더 / 니모닉(IL) 보기, 편집 / 모니터 |
| 편집기 맨 아래 | **PLC 패널 막대**: PB1~PB8 버튼과 연결 단자. [자세히 ▸]로 X·Y 입출력과 PB 연결 단자 바꾸기 |
| 맨 아래 | 상태 바: 렁·스텝, 컴파일 상태, RUN/STOP, 가상 설비 켜짐/꺼짐 |

[▦ 패널]은 구역별로 나뉩니다. **기본**(가상 설비 · 타이밍 차트 · 찾기·교차 참조 · AI 도우미), **학습**(학습 미션), **읽기·점검**(PLC 읽기(기본) · 설치한 PLC 점검), **플러그인**(플러그인 탭과 설치한 플러그인 패널). 맨 위 버튼 줄은 화면 구성을 한 번에 바꿉니다(편집만 · 편집 + 설비 · 디버그). 패널 머리글을 끌어 칸을 옮기거나 ↗ 로 새 창으로 뺄 수 있습니다.

### 실행 막대의 실행 도구
- **⏩ 조건까지**: [멈출 조건]에서 "A+ 끝 (X2 ON)" 같은 순간을 고르면 그 조건이 되는 스캔에서 자동으로 멈춥니다. 목록에 없으면 "디바이스 직접 입력…"에 "Y38 OFF"처럼 씁니다. (가상 30초 제한)
- **⏺ 기록 / ▶ 재생**: 초기화 후 누른 버튼·스위치 입력과 시각을 기록하고, 처음 상태에서 같은 입력을 같은 시각에 다시 넣습니다. 설비 센서는 기록하지 않습니다.

## 3. 래더 편집과 모니터

### 그리기·고치기
- **편집**: 도구 모음의 a접점·b접점·병렬·코일·명령 버튼으로 그립니다. 칸을 더블클릭하면 입력창이 열립니다. 자주 쓰지 않는 명령은 [부호 ▾] 메뉴에 있습니다.
- **코멘트**: 접점·코일을 선택하고 `F4`(또는 [코멘트 편집]).
- **끌어 놓기**: 편집 모드에서 접점·코일을 마우스로 끌어 다른 칸·다른 렁으로 옮깁니다. 놓을 수 있는 칸은 점선, 없는 칸은 붉은 상자로 표시됩니다. `Esc` 로 취소하고 `Ctrl+Z` 한 번으로 되돌립니다.
- **떠 있는 칸 옮기기·복사**: 빈 렁에 놓은(아직 이어지지 않은) 접점·코일은 끌어서 다른 칸·다른 빈 렁으로 옮길 수 있습니다. 칸만 옮겨지고 붙어 있던 선은 그 자리에 남으며, 겹치는 칸이나 이미 이어진 렁에는 놓을 수 없습니다. 키보드로는 `Ctrl+X` 후 도착 칸에서 `Ctrl+V`, 복사는 `Ctrl+C` → `Ctrl+V` 입니다. 결과는 상태 줄로 알려 줍니다.
- **독립 회로 자동 분리**: 한 렁에서 모선에 서로 이어지지 않은 회로가 둘 이상 완성되면 각 회로가 별도 렁으로 나뉩니다(위 행이 처음 렁, 나머지는 바로 뒤). `Ctrl+Z` 한 번으로 되돌립니다.
- **찾기/바꾸기**: `Ctrl+F` 로 디바이스(X15)·명령어(OUT)·코멘트를 찾고, 디바이스 이름을 한꺼번에 바꿉니다(되돌리기 가능). 같은 패널의 **사용 디바이스 목록**은 접점/코일 수, 쓰인 렁, 점검(이중 코일 등)을 보여 줍니다.

### 입력한 명령이 이어 줄 곳을 정합니다 (빈 렁)
아무것도 이어지지 않은 렁에서는 **어떤 명령으로 입력했는지**에 따라 선이 자동으로 이어집니다.
| 입력 | 뜻 | 자동으로 하는 일 |
|---|---|---|
| 병렬 접점 `Shift+F5`·`Shift+F6`·`Alt+F7`·`Alt+F8`, 도구 모음 병렬 버튼, 입력창에 쓴 `OR…` | 바로 위 행 회로의 병렬 가지 | 위 행 접점의 양 끝에 세로선을 긋습니다. 위 행에 이을 접점이 없으면 오류로 이유를 알립니다 |
| 일반 접점 `F5`·`F6` 를 새 행 0열에 입력 | 새 렁의 시작 후보 | 잇지 않고 **떠 있는 칸**으로 둡니다 |
| 코일·응용 명령 `F7`·`F8` | 같은 행 회로의 끝 | 코일 열로 가고, 그 행 접점이 왼쪽 모선에서 이어져 있으면 접점과 코일 사이를 가로선으로 채웁니다 |
| 그 밖에 띄워 놓은 칸 | 아직 정해지지 않음 | 떠 있는 칸으로 두고 `Ctrl+방향키`·`F9` 로 직접 잇습니다 |

- 예: 접점 `X0` 를 놓고 → 아래 행에서 `Shift+F5` 로 `X1` → 코일 `Y0` 를 넣으면 `X0` `X1` 병렬 회로가 한 번에 완성됩니다. 손으로 선을 그은 것과 IL 이 같습니다.
- 연결하지 못한 곳은 흐리게(떠 있음) 남고 **상태 줄에 이유**가 나옵니다. 예: 열이 위 행 접점과 맞지 않음, 바로 위 행이 비어 있음, 코일 앞 접점이 모선에서 끊겨 있음.
- 병렬 접점은 **바로 위 행**과 잇습니다. 세 번째 가지는 두 번째 가지 바로 아래 행에 놓으세요.
- 코일 앞 선 채우기는 그 행의 가장 오른쪽 접점부터 코일까지입니다. 모선과 접점 사이 틈은 채우지 않습니다.
- 이미 이어진 렁은 지금까지와 같습니다(접점 아래 칸에 병렬, 접점 오른쪽 선 위에 직렬). `Ctrl+Z` 한 번으로 되돌립니다.

### 선 그리기
- 가로선 `F9`: 병렬 가지 옆 빈 칸에서 누르면 병렬 블록이 그 칸까지 넓어집니다.
- 세로선 `Shift+F9`: 커서 칸 왼쪽에 아래로 긋습니다. 블록 바깥 열이면 합류점이 그 열로 가고, 접점 위면 그 아래에 병렬 접점을 입력합니다.
- 지우기: `Ctrl+F9`(가로선), `Ctrl+F10`(세로선).
- 래더로 나타낼 수 없는 선(브리지 회로 등)은 그려지지 않고 이유가 상태 줄에 나옵니다.

### 모니터
- **보기**: 통전되는 접점·코일은 주황색으로 채워지고, 타이머·카운터·MOV 는 현재 값이 함께 보입니다.
- **디바이스 테스트**: 모니터에서 접점·코일을 클릭하고 `Shift+Enter` 를 누릅니다.
  - 입력(X): 한 번 눌러 켜 두고, 다시 누르면 끕니다.
  - 출력(Y)·내부 릴레이(M): 강제 ON/OFF 하고, 다시 누르면 해제합니다.

### 화면 보기
- **창 크기에 맞춤**: 패널을 여러 개 열어 편집 창이 좁아지면 래더가 잘리지 않도록 배율이 자동으로 줄어듭니다(25%까지, 그보다 좁으면 가로 스크롤). 글자가 작으면 패널을 닫거나 키우세요. 도구 모음의 [폭에 맞춤]을 끄고 직접 확대할 수도 있습니다.
- **미니맵**: 렁이 10개를 넘으면 래더 왼쪽에 전체 축소 그림이 나옵니다(붉은 막대 = 오류 렁). 누르거나 끌면 그 위치로 이동합니다.

### 제어 흐름 명령 (시뮬레이션)
IL 탭에 쓰면 실행됩니다.
- `P0`: 포인터 줄
- `CJ P0` · `SCJ P0`: 입력 ON 이면 점프
- `CALL P1` … `FEND` 뒤의 `P1` … `RET`: 서브루틴
- `FOR K3` … `NEXT`: 3번 반복

### 특수 릴레이 (SM)
`LD SM412` 처럼 접점으로 읽습니다. 값은 엔진이 스캔마다 채우는 읽기 전용이라 코일(`OUT`·`SET`·`RST`)이나 `MOV` 로 쓰면 입력 단계에서 오류가 납니다. 모니터에서 강제(Shift+Enter)도 걸리지 않습니다. 시계는 시뮬레이션 시간 기준이므로 배속을 올리면 빨라지고 STOP 하면 멈추며 초기화하면 처음부터 다시 시작합니다.

| 번호 | 의미 |
|---|---|
| SM400 | 항상 ON |
| SM401 | 항상 OFF |
| SM402 | RUN 후 첫 스캔만 ON |
| SM403 | RUN 후 첫 스캔만 OFF |
| SM410 | 0.1초 클럭 (0.05초 ON / 0.05초 OFF) |
| SM411 | 0.2초 클럭 |
| SM412 | 1초 클럭 (0.5초 ON / 0.5초 OFF) |
| SM413 | 2초 클럭 (1초 ON / 1초 OFF) |

이 밖의 SM 번호는 아직 지원하지 않으며 "지원하지 않는 특수 릴레이" 오류로 알립니다.

### ST 입력
편집기의 [ST] 탭에 글로 프로그램을 쓸 수 있습니다. ST 는 래더·IL 과 **같은 스캔 안에서 IL 다음에** 실행되고, 프로젝트마다 하나이며 프로젝트 파일에 함께 저장됩니다. 변수 선언은 없고 디바이스(`X0`, `Y20`, `M0`, `D0` …)를 바로 읽고 씁니다.
- 오류가 있으면 아래에 `ST 2줄: …` 로 나옵니다(누르거나 `F8` 로 그 줄로 이동). 오류가 있어도 래더·IL 은 계속 실행되고, ST 는 마지막으로 오류 없던 내용이 그대로 돕니다. 프로젝트를 열 때 오류가 있으면 ST 는 실행하지 않습니다.
- 편집기 머리글의 [예제 ▾]에서 예제를 고르면 편집기 내용이 바뀝니다(`Ctrl+Z` 로 되돌림). [예제 ▾]는 래더·니모닉·ST·SFC 어느 보기에서나 같은 자리에 있고, 지금 보는 보기의 예제만 보여 줍니다(래더·니모닉은 가상 설비용 IL 예제).
- 실제 PLC 에는 ST 를 쓰지 않습니다(시뮬레이션 전용).

| 쓰는 것 | 표기 |
|---|---|
| 주석 | `(* … *)`, `// …` |
| 대입 | `Y0 := X0 AND NOT X1;` (대상: Y·M·L·B·F·D·W) |
| 연산 | `+ - * / MOD`, 비교 `= <> < > <= >=`, 논리 `AND OR XOR NOT` |
| 상수 | `123` `K123` `H1F` `16#FF` `TRUE` `FALSE` |
| 조건 | `IF … THEN … ELSIF … ELSE … END_IF;` `CASE … OF … END_CASE;` |
| 반복 | `FOR D1 := 1 TO 10 DO … END_FOR;` `WHILE … DO … END_WHILE;` `EXIT;` `RETURN;` |
| 간접 지정 | `D[D0]` |
| 타이머·카운터 | `OUT_T(조건, T0, 30);` `OUT_C(조건, C0, 5);` `RST(C0);` — 매 스캔 실행되게 쓰세요(`IF` 안에 넣으면 조건이 꺼질 때 초기화되지 않습니다) |

예제 — X0 를 3초 누르고 있으면 Y21 이 켜지고, X1 을 누르면 D0 에 1부터 10까지의 합이 들어갑니다.
```
OUT_T(X0, T0, 30);
Y21 := T0;
IF X1 THEN
  D0 := 0;
  FOR D1 := 1 TO 10 DO
    D0 := D0 + D1;
  END_FOR;
END_IF;
```
자세한 문법과 한계(변수 선언·함수·실수 없음 등)는 `docs/design/st-engine.md` 에 있습니다.

### SFC 입력
편집기의 [SFC] 탭에서 **순차 제어(스텝과 전이)** 를 씁니다. GX Works2 의 SFC 처럼 **스텝이 하는 일과 다음 스텝으로 넘어가는 조건을 각각 작은 래더로** 씁니다. 한 화면에 세 가지가 있습니다.
- **도식(왼쪽 위)**: 스텝(상자)과 전이(가로 막대)를 그린 그림입니다. **읽기 전용**이고, 스텝·전이를 고르는 용도입니다. 실행 중에는 활성 스텝이 채움색·굵은 테두리·`● 활성` 글자로 표시됩니다. [목록 보기]를 누르면 같은 내용을 목록으로 봅니다.
- **구조 텍스트(오른쪽, 좁으면 아래)**: 스텝·전이를 **추가·삭제·연결하는 유일한 방법**입니다. 아래 문법표대로 씁니다.
- **래더 조각(아래)**: 도식에서 스텝이나 전이를 **클릭하거나 방향키(←→↑↓)로 고르고 `Enter`**(또는 더블클릭)를 누르면, 그 스텝의 동작 래더·그 전이의 조건 래더가 이 자리에 열립니다. 평소 래더 편집기와 똑같이 편집하고(`F3` 로 모니터 모드, 실행 중 통전 표시), 고친 내용은 구조 텍스트의 **그 블록만** 바꿉니다. `Esc`(또는 [닫기])로 도식으로 돌아갑니다. 조각은 한 번에 하나만 엽니다.

동작 규칙(띄움이 정한 규칙이며 GX Works2 와 같다고 주장하지 않습니다):
- 스캔마다 IL → SFC → ST 순서로 실행합니다. 처음 켜면 `INIT` 스텝이 활성이 되고 같은 스캔에 그 동작이 실행됩니다.
- 한 스캔에 한 걸음만 나아갑니다. 막 켜진 스텝은 그 스캔에서 다시 넘어가지 않습니다.
- 같은 스텝에서 나가는 전이가 여럿이면 **파일에 먼저 쓴 전이**가 이깁니다.
- 스텝이 꺼지면 그 동작에서 `OUT` 으로 켜던 비트는 꺼지고, `OUT T` 타이머는 초기화됩니다. `SET`·`RST`·`MOV` 등으로 쓴 값은 그대로 남습니다(`OUT` = 비저장, `SET` = 저장).
- 스텝이 활성인 동안 `AT` 로 지정한 비트가 켜집니다. 래더에서는 일반 M 접점으로, 감시창에서는 값으로 보입니다.
- **SFC 를 고쳐 확정하면 STOP → RUN 처럼 처음부터 다시 시작합니다**(스텝 상태가 초기화됩니다). 래더·IL 을 고쳤을 때와 같습니다.
- **시뮬레이터 전용**입니다. 실제 PLC 로 쓰지 않고, 실제 PLC 에 연결(모니터)한 동안에는 동작하지 않습니다.
- 오류는 아래에 `SFC 5줄: …` 로 나옵니다(누르거나 `F8` 로 그 줄로 이동). 오류가 있으면 SFC 는 마지막으로 오류 없던 내용이 그대로 돌고, 도식도 그 내용을 보여 줍니다. 프로젝트를 열 때 오류가 있으면 SFC 는 실행하지 않습니다.
- 편집기 머리글의 [예제 ▾]에 예제 3개(신호등 · 선택 분기 · 병렬 분기)가 있습니다. 고르면 구조 텍스트 내용이 바뀝니다(`Ctrl+Z` 로 되돌림).

| 쓰는 것 | 표기 |
|---|---|
| 주석 | 구조 줄은 `// …`, IL 줄은 `; …` |
| 스텝 | `STEP S1 '코멘트' AT M101` … `END_STEP` — 번호 `S0`~`S511`, **초기 스텝은 `INIT`(1개 이상 필요)**, 코멘트는 32자까지, `AT` 는 Y·M·L·B·F 비트 |
| 전이 | `TRANSITION TR1 S0 -> S1 '코멘트'` … `END_TRANSITION` — 번호 `TR0`~`TR9999` |
| 선택 분기 · 합류 | 같은 스텝에서 나가는 전이를 여럿 쓰면 분기, 같은 스텝으로 들어가는 전이를 여럿 쓰면 합류 |
| 병렬(동시) 분기 | 목적이 여럿: `TRANSITION TR1 S0 -> S1, S2` (한 번에 모두 켭니다) |
| 병렬(동시) 합류 | 원천이 여럿: `TRANSITION TR4 S3, S4 -> S5` (모두 활성일 때만 평가합니다) |
| 동작 조각 | `STEP` 과 `END_STEP` 사이의 IL. 스텝이 활성인 동안 매 스캔 실행하고, 마지막 줄은 `END` |
| 전이 조건 조각 | `TRANSITION` 과 `END_TRANSITION` 사이의 IL. 접점 뒤에 **`TRAN` 코일 하나**를 두고 `END` (예: `LD T0` `TRAN` `END`) |
| 조각 안에서 못 쓰는 것 | 포인터 `P`, `CJ`, `SCJ`, `CALL`, `RET`, `FEND`, `FOR`, `NEXT`, `MC`, `MCR`, 마지막 줄 말고 `END`. 전이 조각에서는 `TRAN` 앞의 출력 명령 |
| 스텝 경과 시간 | 동작 조각에 `OUT T0 K30`(3초), 전이 조각에 `LD T0` |

예제 — 신호등(빨강 3초 → 초록 3초 → 노랑 1초를 되풀이): 스텝 3개와 전이 3개입니다. 각 스텝은 자기 램프를 켜고 타이머를 돌리며, 전이는 그 타이머가 끝나면 켜집니다.
```
STEP S0 INIT '빨강' AT M100
  LD SM400
  OUT Y0
  LD SM400
  OUT T0 K30
  END
END_STEP
STEP S1 '초록' AT M101
  LD SM400
  OUT Y2
  LD SM400
  OUT T1 K30
  END
END_STEP
STEP S2 '노랑' AT M102
  LD SM400
  OUT Y1
  LD SM400
  OUT T2 K10
  END
END_STEP
TRANSITION TR1 S0 -> S1
  LD T0
  TRAN
  END
END_TRANSITION
TRANSITION TR2 S1 -> S2
  LD T1
  TRAN
  END
END_TRANSITION
TRANSITION TR3 S2 -> S0
  LD T2
  TRAN
  END
END_TRANSITION
```
이 글을 [SFC] 탭에 쓰고 [RUN]을 누르면 도식에서 S0 → S1 → S2 → S0 순으로 활성 스텝이 옮겨 가고, Y0·Y2·Y1 램프가 차례로 켜집니다. 도식에서 `S1` 을 고르고 `Enter` 를 누르면 그 스텝의 동작 래더가 열려, 래더로 `OUT Y2` 를 고칠 수 있습니다.

**GX Works2 의 SFC 와 다른 점·하지 않는 것**: 블록(0~319)·END 스텝·JUMP 기호·스텝 속성 5종 선택·리셋 스텝·모니터의 보류(노랑) 색은 없습니다. 도식에서 직접 스텝·전이를 끌어 놓지 못하고(구조는 글로만), 모니터 중에도 편집을 막지 않습니다(고치면 처음부터 다시 시작). GX Works2 파일(`.gxw`)·CSV 와 SFC 를 주고받지 않습니다. 자세한 설계는 `docs/design/sfc.md` 에 있습니다.

## 4. PLC 패널 (PB 버튼)
- PB1~PB8 은 실습대의 푸시버튼입니다. 누르는 동안만 ON 이고, `Shift+클릭` 은 눌러 둔 채로 유지합니다.
- 기본 연결: PB1~PB4 → X15~X18. 연결 단자는 [자세히 ▸]에서 바꿉니다. `.gxw` 를 열면 프로그램이 쓰는 입력에 자동으로 연결됩니다.
- 가상 설비의 센서(X1~X4 등)는 설비가 값을 정하므로 패널에서 누를 수 없습니다(🔒).

## 5. 가상 설비
[▦ 패널 → 가상 설비]를 켜면 실습대(실린더 A 양솔 Y38/Y39·X1/X2, B 편솔 Y3A·X3/X4, C 편솔 Y3B)가 래더와 이어집니다. 꺼져 있으면 일반 PLC 로 동작합니다. 실습대용 프로그램은 편집기 머리글의 [예제 ▾]에서 불러옵니다.

### 설비 더하기 — [설비 추가 ▾] 하나
가상 설비 창의 [설비 추가 ▾] 메뉴가 설비를 더하는 **유일한 입구**입니다(예전에 "설비·배선 설정" 안에 있던 추가 막대는 없어졌습니다). 메뉴는 구역으로 나뉩니다.
- **기본 설비**: 실린더·센서 실습대·컨베이어·그리퍼·모터·시퀀스 등. 고르면 한 대 더해집니다.
- **예제 설비**: 아래 "내 설비 추가"의 6종. 내 설비는 최대 3개이고, 넘으면 먼저 연 설비부터 제거됩니다.
- **확장팩 설비**: [플러그인] 탭에서 설비 확장팩을 받으면 여기에 나타납니다(내 설비 3개에 세지 않음).
- **가져오기 · 만들기 · 받기**: [📂 파일에서 가져오기…](코드가 든 설비 파일은 기존처럼 확인 창을 거침) · [🤖 AI 로 설비 만들기](제안은 [적용]을 눌러야 반영) · [🧩 확장팩 받기…](플러그인 탭을 엽니다).

"설비·배선 설정" 안의 설비 목록은 위쪽 장면에 이미 있는 실린더와 "내 설비" 카드에 이미 있는 설비의 그림을 다시 그리지 않습니다. 이름·[초기화]·[삭제]·설정(파라미터)만 있고, 실린더는 [공압 회로도] 버튼을 눌러야 회로도가 펼쳐집니다. 컨베이어·그리퍼·모터·센서 실습대·시퀀스는 목록 안에 그림이 있어, 더하면 그 영역이 자동으로 펼쳐집니다.

### 래더와 그림 연결
- 래더에서 접점·코일을 누르면, 그 디바이스와 이어진 센서·솔레노이드가 그림에서 점선 테두리와 주소(예: ◀ X1)로 표시됩니다.
- 거꾸로 그림의 센서·솔레노이드를 누르면 그 디바이스를 쓰는 렁으로 이동합니다. 여러 곳이면 첫 번째로 가고, 나머지는 `Ctrl+F` 로 찾습니다.

### 원인 찾기와 그래프
- **❓ 왜 안 움직이나?**: 그림 아래 버튼을 누르면 실린더마다 원인 후보가 나옵니다. 표시는 ✘ 원인 · ! 주의 · ✔ 정상 입니다. 규칙으로 풀리지 않으면 결과 상자 머리글의 **[🤖 AI 에게 물어보기]**를 누르세요. 원인 후보가 AI 도우미 입력칸에 채워진 채 도우미가 열리고, 내용을 확인해 [보내기]를 눌러야 AI 에게 갑니다(처음 보낼 때 기존과 같은 동의 확인이 뜹니다). 이 버튼 없이도 규칙 진단은 AI 없이 그대로 쓸 수 있습니다.
  - 솔레노이드 출력이 꺼져 있으면 그 출력을 켜는 렁에서 막고 있는 접점
  - 공급 압력이 낮음, 고장 주입 중, 이미 끝까지 감, 양솔 동시 ON 등
- **변위–단계 선도**: 그림 아래 "변위–단계 선도"를 펼치면 실린더가 단계마다 전진(1)·후진(0)한 모습이 표준 공압 선도로 그려집니다. 진행 중은 점선, 지금 단계는 굵은 테두리와 "지금"으로 표시됩니다.

### 실린더 모델 (실린더 설정)
| 설정 | 효과 |
|---|---|
| 출발 지연(L1) | 밸브가 바뀐 뒤 그만큼 기다렸다 움직입니다 |
| 쿠션 길이(L1) | 행정 끝에서 천천히 멈춥니다 |
| 압력 시정수(L2) | 양쪽 챔버 압력이 서서히 차고 빠지며, 그림 왼쪽 아래에 압력 그래프(실선 전진실, 점선 후진실, 최근 2초)가 나옵니다 |

모두 0 이면 꺼지며, 미션 채점은 이 기본값 기준입니다. 공기가 흐르는 배관에는 흰 점이 흐르고, '움직임 줄이기'나 STOP 에서는 흰 화살표로만 방향을 표시합니다.

### 내 설비 추가
학습용 예제 설비 6종이 있습니다.

| 설비 | 내용 |
|---|---|
| 자동문 | 문 앞 사람 감지로 열고 닫기 |
| 물탱크 수위 제어 | 수위에 따라 급수·배수 |
| 신호등 | 보행자 버튼 |
| 포장 라인 | 워크 카운트 |
| 항온조 | 히터·팬 |
| LED 패널 | L1~L8 = 실습대와 같은 Y20~Y27 (연결 주소는 [배선]에서 바꿈) |

- 각 설비는 카드에서 사용자가 조작(문 앞 사람, 누수, 워크 투입 …)할 수 있고, 연결 주소가 표시됩니다.
- 설비는 프로젝트에 함께 저장됩니다.

### 내 설비 고치기·나누기
- **이름 바꾸기**: 설비 카드의 [이름].
- **복제**: [복제]로 같은 설비를 새 id 로 하나 더 만들어 고쳐 씁니다. 예제 설비를 고치면 예제는 그대로 두고 새 id 로 만들어집니다.
- **내보내기·가져오기**: [내보내기]로 설비 설명서(.json)를 저장해 다른 사람에게 줄 수 있고, 받은 사람은 [📂 파일에서 가져오기]를 씁니다.
- **🤖 AI 로 수정**: "문을 더 천천히 열어 줘"처럼 말하면 AI 도우미가 설비의 설명서를 보고 고친 제안을 냅니다. [적용]을 누르면 같은 연결 주소를 유지한 채 설비가 바뀝니다.
- **🤖 AI 로 설비 만들기**: 원하는 설비를 말로 설명하면 설명서를 제안합니다. 검사를 통과하면 [적용]으로 추가됩니다.

### 코드 설비
JavaScript 코드가 든 설비 파일(`{ …, "code": "definePlant({ … })" }`)도 [📂 파일에서 가져오기]로 열 수 있습니다.
- 확인 창에서 허락하면 코드는 격리된 공간에서만 돌고, PC 의 파일·네트워크에 접근할 수 없습니다.
- 1초 넘게 응답이 없으면 멈추고, 그림에 "응답 없음"이 표시됩니다.
- 프로젝트에 함께 저장되고, 그 프로젝트를 열 때 다시 허락을 묻습니다.
- 이름 바꾸기·복제·내보내기는 되지만, AI 로 고치기는 설명서 방식 설비만 됩니다.

## 6. 학습 미션
- [학습 미션] 탭에서 39개 미션을 순서대로 풉니다.
  - 기본 1~10, 실습대 11~14, 값·비교 15~17
  - 내 설비 18~23: 자동문·물탱크·신호등·포장 라인·항온조·LED 패널
  - 고장 24~27: 실습대 실린더에 고장을 넣어 두고 경보·복구를 짭니다.
  - 기본 보충과 **오류 찾기** 28~35: 다수결·알람 래치·OFF 딜레이·두 타이머·램프 순환, 그리고 일부러 틀린 프로그램이 시작 코드로 주어지는 문제(30 이중 코일, 32 정지 접점·타이머 값, 34 정/역 운전 인터록). 오류 찾기는 에디터에 불러온 프로그램을 고쳐서 채점을 통과시킵니다.
  - 실습대 심화 36~39: 세 번 왕복·연속 왕복과 사이클 끝 정지·비상 정지·두 실린더 상호 인터록
- 편집기에서 프로그램을 짜고 **채점** 을 누릅니다.
- 내 설비 미션은 설비를 직접 추가하지 않아도 채점됩니다. 설비 카드를 추가해 두면 같은 설비로 눈으로도 확인할 수 있습니다(연결 주소는 미션 표의 주소 그대로).
- 막히면 **힌트**(3단계)를 보고, 실패 지점·그때의 신호 값·출제자 조언을 확인합니다.
- 채점 결과는 가상 설비 그림 위에도 덮개로 뜹니다. 실패하면 몇 번째 단계에서 기대와 달랐는지와 관련 센서·솔레노이드가 그림에서 강조됩니다([닫기]로 닫음).
- **🤖 AI 에게 물어보기**: 채점 결과를 AI 도우미에게 보냅니다. 정답은 숨기고 단서만 받습니다.

### 학습 모드 (플러그인, 선택)
내가 짠 래더(또는 예제)를 **한 렁씩 풀어서 설명**해 주고, 가상 PLC 에서 직접 켜 보며 확인하는 기능입니다. 미션은 "문제를 풀어 채점"하고, 학습 모드는 "이미 있는 래더를 이해"하는 데 씁니다.

**준비**: [플러그인] 탭에서 **학습 모드**를 받습니다(앱 1.3.0 이상). 그러면 [▦ 패널 → 플러그인]에 **학습 모드** 패널이 생깁니다. 처음에 권한(프로그램 읽기·화면 표시·가상 PLC 읽기와 신호 넣기·래더 강조·AI 질문·저장)을 한 번에 승인합니다. 실제 PLC 나 장비에는 아무것도 보내지 않습니다.

**쓰는 순서**
1. 편집기에 래더를 불러옵니다. 연습하려면 [예제 ▾]에서 ② 자기유지·③ 타이머·④ 카운터·⑤ 인터록·⑥ 비교 예제를 고릅니다.
2. 실행 모드를 **시뮬레이션**(가상 PLC)으로 둡니다. 다른 모드에서는 [설명만 보기]만 쓸 수 있습니다.
3. 패널에서 **[학습 시작]**을 누릅니다. 프로그램을 렁 단위로 나눈 개요가 나옵니다. 시작 전에 가상 PLC 를 잠시 쓴다는 확인 창이 뜹니다.
4. **[첫 단계 ▶]**. 단계마다 ① 이 단계가 무슨 일을 하는지 글로 설명 ② 신호가 어디로 가는지 표 ③ 확인 동작이 나옵니다. 설명이 나오는 동안 래더에서 해당 렁이 강조됩니다.
5. **[해 보기 ▶]**를 누르면 앱이 센서·버튼 신호를 **자동으로 넣어** 가상 PLC 를 돌리고, 기대한 대로 켜졌다 꺼지는지 판정합니다. 통과하면 **[다음 ▶]**이 열립니다.
6. 마지막 단계 뒤에 요약(통과·건너뜀·설명만)이 나오고, 가상 PLC 는 시작 전 상태로 돌아갑니다. 언제든 **[종료]**로 끝낼 수 있습니다.

**속도 조절**: 확인이 실행되는 동안 [느리게] [보통 속도] [멈춤] [계속] [한 스캔] [다음 변화]를 쓸 수 있습니다. [속도 방식]에서 자동(변화가 생길 때 느리게) · 변화마다 멈춤 · 한 스캔씩 · 느리게 중에 고르면 다음 실행에도 기억합니다.

**반복과 건너뛰기**: 확인이 실패하면 이유(기대한 것·어느 렁·넣은 입력)가 나오고 **[다시]**로 같은 확인을 반복합니다. 한 단계에서 **3번 연속 실패하면 [건너뛰기]**가 나옵니다. 자동 확인은 앱이 만든 것이라 프로그램이 맞아도 실패할 수 있기 때문입니다. 건너뛰어도 요약에 "건너뜀"으로 남을 뿐 학습은 이어집니다. 프로그램을 고치거나 실행 모드를 바꾸면 확인이 끝나고 처음으로 돌아갑니다.

**질문칸**: 패널 아래 입력칸에 모르는 것을 쓰고 **[질문하기]**를 누릅니다.
- 명령어 이름(`OUT`)이나 개념 이름("자기 유지")은 **AI 없이 바로** 사전·개념 카드로 답합니다. 카드에서 [더 쉽게]·[예로 보기]를 고를 수 있습니다.
- "왜 안 켜져?"는 지금 신호 값을 보고 어느 접점이 막는지 알려 줍니다(단순한 직렬 렁일 때).
- 그 밖의 질문은 **AI 가 연결돼 있고 동의했을 때만** AI 로 보냅니다. 질문은 한 번에 하나, 너무 빠르게 연달아 보내면 잠시 기다리라고 나옵니다. AI 에는 이 단계의 제목·해당 렁·지금 값만 가고, 정답 코드를 달라고 하지 않습니다.
- **AI 가 없으면** 사전·개념 답은 그대로 나오고, 사전에 없는 질문에는 "사전에서 찾지 못했습니다"와 비슷한 항목이 나옵니다. [AI 에게 더 물어보기] 단추는 보이지 않습니다. 학습 자체는 AI 없이 끝까지 됩니다.

**내 기억(어려워하는 개념)**: 어떤 개념에서 자주 실패하거나 질문하면 앱이 이 PC 에만 기록해 두었다가, 다음 단계에서 **보강 카드**(더 쉬운 설명)를 보여 줍니다. [기억 보기]로 내용을 보고 [기억 지우기](두 번 눌러야 지워짐)로 지우며, [기억 사용]을 끄면 기록을 멈춥니다. 공용 PC 에서는 끄세요. AI 에는 "어려워하는 개념 이름"만 가고 질문 원문은 가지 않습니다. 플러그인을 제거하면 기억도 지워집니다.

**가상 설비(실습대)와 함께 쓸 때**
- 가상 설비가 **꺼져 있으면**: 래더의 코멘트로 센서를 알아보고(예: X2 = A 전진단 센서) 그 신호를 앱이 대신 넣습니다. 이때 화면 위에 "가정한 센서입니다 — 실제 설비가 아닙니다"가 항상 보입니다.
- 가상 설비가 **켜져 있으면**: 센서(X1~X4 등)는 설비가 정하므로 앱이 신호를 넣지 않습니다. 센서가 필요한 확인은 만들지 않고 이유를 적어 줍니다. 설비 표에서 실린더 상태를 함께 볼 수 있습니다.

**한계**: 이중 코일·강제로 켠 디바이스 같은 문제가 있으면 먼저 문제 목록을 보여 주고 확인하지 않습니다. 단계가 아주 많으면 앞부분만 보입니다. 비교 접점만 있는 단계는 설명만 합니다. 영어 화면에서는 문구가 영어로 나옵니다.

## 7. AI 도우미
### 시작하기
1. [▦ 패널 → AI 도우미]를 켭니다.
2. 머리글에서 **Claude Code · Antigravity CLI(agy) · Codex CLI · 로컬 AI · 사용자 지정** 중에서 고릅니다. (CLI 는 미리 설치·로그인되어 있어야 합니다)
3. ⚙ 에서 설정한 뒤 **[연결 테스트]** 로 확인합니다.
4. 모델은 ⚙ 설정에서 고릅니다. 목록에 없으면 "직접 입력…", 기본 모델을 쓰려면 "(기본 모델)"을 고릅니다. (Codex 는 CLI 가 알려 주는 목록, Claude Code 는 별칭·알려진 이름)

### 쓰는 법
- 말로 설명하면 프로그램·코멘트·PB 연결·새 설비를 **제안**합니다.
- 제안 카드의 **[적용]** 을 눌러야 반영됩니다. 프로그램 제안은 컴파일 검사를 통과해야 하고, 프로그램/PB 는 **[되돌리기]** 가 됩니다.
- **❓ 왜 안 되죠?**: 먼저 앱이 STOP·컴파일 오류·PB 연결·가상 설비 꺼짐 등을 즉시 점검하고, 같은 상태를 AI 에게 넘겨 원인을 묻습니다.
- **이미지 질문**: 🖼 파일 / 붙여넣기 / 끌어놓기 / 📷 화면 캡처. (Claude·Codex·비전 모델 로컬 AI)

### 개인정보
- 질문은 선택한 AI(클라우드 또는 내 컴퓨터)로 전송됩니다. 처음 쓸 때 동의를 받습니다.
- 비밀번호·개인정보가 보이는 화면은 첨부하지 마세요.
- 에이전트는 도구 없이 대화만 하고, 실제 PLC 에는 아무것도 쓸 수 없습니다.

## 8. 파일
### 프로젝트와 가져오기
- 프로젝트는 `.plcproj`(프로그램·ST·SFC·코멘트·설비·PB 연결)입니다. 자동 저장되며, 비정상 종료 뒤 복구를 제안합니다.
- **GX Works2 `.gxw`** 를 [열기]로 열면 프로그램(MAIN)과 디바이스 코멘트를 가져옵니다. 원본은 바꾸지 않고, 저장하면 새 `.plcproj` 가 됩니다. 지원하지 않는 명령이 있으면 위치와 함께 알려 줍니다.
- 래더 도구 모음의 [⋯] 메뉴에서 GX Works2 목록 CSV 를 가져오거나 내보냅니다.
- **타이밍 차트 내보내기**: 타이밍 차트의 [내보내기 ▾]에서 고릅니다.
  - "CSV(표)": 신호 값이 바뀐 시각(ms)과 값을 엑셀에서 열 수 있는 표로 저장
  - "PNG(그림)": 지금 보이는 파형을 그림으로 저장

### PLC 로 직접 쓰기
상단 막대의 **[PLC 에 쓰기]** 버튼을 씁니다.
1. FTP 로그인(PLC 의 내장 이더넷 설정에서 정한 이름·비밀번호)을 넣습니다. 비밀번호는 기본으로 저장하지 않습니다.
2. [미리 보기]로 새 프로그램의 스텝 수와 주의 사항을 봅니다.
3. [PLC 에 쓰기…]를 누르면 확인 창이 뜹니다. 기본 버튼은 취소이므로 마우스로 [PLC 에 쓰기]를 눌러야 진행됩니다.
4. 앱이 다음 순서로 진행합니다: PLC STOP → 지금 파일 삭제·새 파일 쓰기 → 다시 읽어 비교 → 같을 때만 RUN.

참고할 점:
- **로그인 기억**: "이 PC 에 로그인 기억"을 켜면, 미리 보기가 성공한 뒤 이 PC 의 내 Windows 계정으로 암호화해 저장합니다. 다음부터 비밀번호 칸을 비워 두면 저장된 것을 쓰고, [저장된 비밀번호 지우기]로 삭제합니다.
- **백업**: 쓰기 전 PLC 의 원본을 앱 데이터 폴더의 `plc-backups` 에 백업합니다. 중간에 실패하면 PLC 는 STOP 으로 남으며, 백업이나 GX Works2 로 복구합니다.
- **쓸 수 있는 명령**: 미리 보기에서 확인된 명령(접점·코일·타이머·카운터·비교·MOV·산술 등)만 씁니다. 모르는 명령이 있으면 어느 줄인지 알려 주고 쓰지 않습니다.
- **한글**: PLC 프로그램 파일은 영문 ASCII 글자만 저장합니다. 한글이 든 줄 문장·노트는 빼고 쓰며(미리 보기·확인 창의 "주의"에 표시) 프로그램 동작에는 영향이 없습니다. 한글 머리글이 있으면 쓰지 않습니다.
- **안전**: 실린더·모터 주변을 확인하고 쓰세요.
- **처음 준비·오류**: 대화상자의 **"FTP 준비 방법"** 에 처음 준비하는 순서가 있습니다. 연결 오류가 나면 원인(FTP 꺼짐·응답 없음·로그인 거부·PLC 주소 미적용)과 할 일을 알려 줍니다.

### 백업에서 되돌리기
1. 같은 창 아래의 목록에서 백업(쓰기 때마다 앱이 저장한 PLC 의 원래 프로그램)을 고릅니다.
2. [되돌리기…]를 누르면 같은 안전 순서로 되돌립니다.
3. 되돌리기 직전의 프로그램도 다시 백업됩니다.
4. 장치 할당이 다른 PLC 의 백업은 쓰지 않습니다.

## 9. 실제 PLC 연결 (선택)
실행 막대 오른쪽의 세 모드 중 하나를 **한 번 누르면** 필요한 단계(접속·쓰기·RUN)를 앱이 차례로 진행합니다. 먼저 [⚙ 설정 → PLC 연결]에 PLC 의 IP 와 포트(5010)를 넣고 [설정 적용]만 해 두세요.

| 모드 | 한 번 누르면 | 언제 쓰나 |
|---|---|---|
| **가상 PLC** | 앱 안의 가상 PLC·가상 설비로 연습 | 장비 없이 연습 |
| **PLC 실행** | 접속 → 프로그램을 PLC 에 쓰기(**확인 창 1번**) → PLC RUN → 래더 모니터로 PLC 의 실제 상태 보기 | 내가 짠 프로그램을 PLC 가 직접 실행하게 할 때. 입력은 PLC 의 실제 버튼, 앱은 상태만 봅니다. 끝낼 때는 배너의 **[PLC 정지]** |
| **앱 구동** | 접속 → 쓰기 켜기 → PLC STOP → 앱의 래더가 PLC 출력(Y)을 직접 구동·RUN 자동 (**확인 창 1번**) | PLC 에 프로그램을 쓰지 않고 앱이 장비를 움직일 때 |

- **처음 한 번만**: [PLC 실행]을 처음 누르면 FTP 로그인(PLC 파라미터의 FTP Setting 값)을 받는 쓰기 창이 열립니다. "이 PC 에 로그인 기억"이 켜진 채 [미리 보기 → PLC 에 쓰기]를 하면, 그다음부터는 [PLC 실행] 한 번으로 끝납니다.
- 접속이 안 돼 있어도 저장된 설정으로 자동 접속합니다(실패하면 이유와 설정 화면을 보여 줍니다).
- **안전**: 쓰기 확인 창은 마우스로 직접 눌러야 하고(기본은 [취소]), 쓰기 전 PLC 원본이 자동 백업됩니다. 에어·구동부 주변을 확인하세요. 앱 구동에서 STOP 을 누르거나 연결이 끊기면 출력이 모두 꺼집니다.
- **PLC 실행 중에는 앱의 PB 버튼으로 입력할 수 없습니다**(PLC 가 돌기 때문). PLC 의 실제 버튼을 누르세요. 앱 구동 중에 PLC 가 RUN 이면 PLC 프로그램이 출력을 덮어쓰므로 앱이 STOP 을 보냅니다.
- PLC 실행 모니터가 읽는 범위는 설정의 "읽을 디바이스"(기본 X·Y 0~7F, M 0~FF, D 0~3F, T·C 일부)입니다. 범위 밖 디바이스는 꺼진 것으로 보입니다.

### PLC 점검 도구 (플러그인, 선택)
[플러그인] 탭에서 **PLC 점검 도구**를 받으면 [▦ 패널 → 읽기·점검]에 **PLC 점검** 패널이 생기고, 한 화면에 위에서 아래로 연결 상태 → 감시 경보 → 배선표 대조 → PLC 구성 순서로 보입니다. 탭을 오갈 필요가 없습니다(기본 탑재 "PLC 읽기(기본)" — CPU 상태·연결 찾기·변화 기록 — 와는 별개). 모두 **PLC 에 쓰지 않고 읽기만** 합니다. 실제 PLC 에서는 아직 확인하지 못했습니다(미검증).
- **PLC 구성(맨 아래 구역)**: PLC 의 FTP 로 `PARAM.QPA`·`COMMENT.QCD` 두 파일만 읽어 I/O 할당·CC-Link 설정·코멘트를 보여 줍니다(FTP 비밀번호는 앱이 가려서 전달). PLC 연결과 저장된 FTP 로그인이 필요합니다.
- **감시 경보**: X·Y·M 접점을 읽어 단계 시간 초과·금지 쌍 동시 ON·연결 끊김을 알립니다. 화면이 갱신되는 동안만 감시합니다.
- **배선표 대조**: I/O 배선표를 붙여 넣으면 X·Y 현재 값과 비교해 어긋난 곳을 목록으로 보입니다.
- 설치할 때 권한 세 가지(PLC 값 읽기·PLC 설정 파일 읽기·화면 표시)를 한 번에 승인합니다. 예전에 **PLC 구성 읽기·감시 경보·배선표 대조**를 따로 받았다면 목록에 "이 앱 목록에 없는 플러그인"으로 남아 계속 동작하며 [제거]만 할 수 있습니다. PLC 점검 도구를 받은 뒤 제거해도 됩니다.

### GX Works2 와 함께 쓸 때 (PLC 설정이 사라지지 않게)
GX Works2 에서 프로젝트를 PLC 에 쓰면 **그 프로젝트의 PLC 파라미터가 PLC 에 덮어써집니다.** Open Setting(MC 5010)·FTP 가 프로젝트 파라미터에 없으면 쓸 때마다 사라집니다. 방법은 셋 중 하나입니다.
1. 쓰는 프로젝트의 **PLC 파라미터에도 Open Setting·FTP Setting 을 넣어 저장**해 두고(틀 프로젝트), 이 앱의 CSV 는 새 프로젝트가 아니라 **그 틀 프로젝트에 읽어 옵니다**(Edit → Read from CSV File).
2. Write to PLC 에서 **Program(Main) 만 체크**하고 PLC Parameter 는 뺍니다.
3. 이 앱의 **[PLC 에 쓰기]** 를 씁니다. 프로그램 파일(MAIN.QPG)만 쓰므로 파라미터가 그대로 남습니다.

접속이 안 될 때는 [⚙ 설정 → PLC 연결]의 **[연결 진단]** 이 어느 설정이 PLC 에 없는지 알려 줍니다.

| 증상 | 확인 |
|---|---|
| 버튼을 눌러도 아무 일도 없다 | 상태 바가 **STOP** 인가? → ▶ RUN. 안내 토스트의 [▶ RUN] 도 쓸 수 있습니다 |
| 모니터에 주황색이 안 보인다 | [모니터]를 켰는지, RUN 인지, PB 연결 단자가 프로그램의 입력과 같은지 |
| 실린더가 안 움직인다 | 상태 바가 **가상 설비 켜짐** 인지, 프로그램이 Y38/Y39/Y3A/Y3B 를 쓰는지, 센서 X1~X4 조건 |
| 프로그램이 실행되지 않는다 | 상태 바의 컴파일 오류, 끝에 `END` 가 있는지 |
| 앱이 안 열린다(Windows) | 스마트 앱 컨트롤이 서명 없는 실행 파일을 막을 수 있습니다 — 서명된 설치 파일을 쓰거나 해당 기능 설정을 확인하세요 |
| 그래도 모르겠다 | [? 도움말 → 진단 정보 복사]로 상태를 복사해 문의에 붙여 넣으세요 |

### 업데이트
앱이 시작할 때(설정 → 업데이트에서 끌 수 있음)와 [설정 → 업데이트 → 지금 확인]에서 새 버전을 확인합니다. [도움말 → 설정 열기]로 그 화면을 바로 열 수 있습니다. 새 버전 알림은 오른쪽 아래에 뜹니다.
- **설치형은 자동으로 받아 둡니다.** 새 버전을 알면 설치 파일(약 128MB)을 백그라운드로 받아 SHA-256 을 확인해 둡니다. 데이터 사용량이 걱정되면 설정 → 업데이트에서 "설치 파일을 미리 받아 두기"를 끄세요.
- 다 받으면 오른쪽 아래 알림에 [지금 다시 시작해 설치]가 뜹니다. 누르면 확인 창 없이 앱을 닫고 설치한 뒤 자동으로 다시 시작합니다. 단, 실제 PLC 에 쓰기가 켜져 있으면 "출력이 꺼진다"는 확인 창이 한 번 뜹니다.
- 누르지 않아도 **앱을 닫을 때 받아 둔 새 버전이 자동으로 설치됩니다**(설치 뒤 앱을 다시 켜지는 않습니다). 끄려면 설정 → 업데이트의 "앱을 닫을 때 자동으로 설치"를 끄세요.
- [지금 확인]을 눌렀을 때 새 버전이 있으면 바로 받아 설치를 진행합니다(받아 둔 것이 있으면 곧바로 설치).
- 설치가 끝나지 않으면 다음 실행에서 알리고, 기록(`update-log.txt`, 앱 데이터 폴더)과 받은 설치 파일 위치를 안내합니다. 그 파일을 탐색기에서 직접 실행해도 됩니다.
- **휴대용·웹 방식**: 자동 설치는 하지 않습니다. [업데이트]를 누르면 새 파일을 다운로드 폴더에 받아 위치를 보여 주니, 기존 파일 대신 그 파일로 실행하세요.

## 11. 단축키
### 파일·보기
| 키 | 동작 |
|---|---|
| `Ctrl+N` / `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S` | 새 프로젝트 / 열기 / 저장 / 다른 이름으로 저장 |
| `Ctrl+F` | 찾기·교차 참조 |
| `F2` / `F3` | 편집(쓰기) 모드 / 모니터 모드 |
| `Ctrl+G` | 스텝 번호로 이동(번호를 입력하고 Enter) |
| `Ctrl+L` | 줄 문장(렁 머리글) 목록 — 고르면 그 렁으로 이동 |

### 접점·코일 입력
| 키 | 동작 |
|---|---|
| `Enter` (편집) | 칸 입력창 열기 |
| `F5` / `F6` | a접점(LD) / b접점(LDI) |
| `Shift+F5` / `Shift+F6` | 병렬 a접점(OR) / 병렬 b접점(ORI) |
| `F7` | 코일(OUT) |
| `F8` | 응용 명령 목록 창: `↑↓` 로 고르고 `Enter` 로 입력창에 채움(글자를 치면 걸러짐). 응용 명령 상자는 GX Works2 처럼 `[+  K1  D0  ]` 괄호 모양으로 그려짐 |
| `Shift+F7` / `Shift+F8` | 상승 / 하강 펄스 접점(LDP / LDF) |
| `Alt+F7` / `Alt+F8` | 병렬 상승 / 하강 펄스 접점(ORP / ORF) |
| `Shift+Alt+F5` / `Shift+Alt+F6` | 닫힘 상승 / 하강 펄스 접점(LDPI / LDFI): 펄스 순간만 끊기고 나머지는 통전 |
| `Shift+Alt+F7` / `Shift+Alt+F8` | 병렬 닫힘 상승 / 하강 펄스 접점(ORPI / ORFI) |
| `Alt+F5` / `Ctrl+Alt+F5` / `Ctrl+Alt+F10` | 연산 결과 상승 펄스(MEP) / 하강 펄스(MEF) / 반전(INV) |
| `Ctrl+/` | 커서의 a접점 ↔ b접점 바꾸기(입력창이 바꾼 명령으로 열림, Enter 로 확정) |
| 입력창이 열린 채로 `F5`·`F6`·`Shift+F5/F6`·`F7`·`Shift+F7/F8`·`Alt+F7/F8`·`Shift+Alt+F5~F8`·`Ctrl+/` | 입력 중인 접점 종류를 바로 바꿈(디바이스는 그대로) |
| `F4` | 디바이스 코멘트 편집(GX Works2 의 `F4` 는 컴파일이라 다릅니다) |

### 입력창 안
| 키 | 동작 |
|---|---|
| `Alt+↑` / `Alt+↓` | 첫 디바이스 번호 증가 / 감소(X·Y 는 16진수) |
| `Ctrl+Space` | 명령 후보 목록(고르면 입력창이 그 명령으로 다시 열림) |
| `Ctrl+Alt+Enter` | 명령 일부 편집: 입력창을 열고 첫 디바이스를 선택해 둠 |

### 이동·찾기·보기
| 키 | 동작 |
|---|---|
| `Ctrl+Alt+E` / `Ctrl+Alt+D` / `Ctrl+Alt+F` | 같은 디바이스의 다음 칸 / 다음 접점 / 다음 코일로 이동 |
| `Ctrl+Alt+R` | 위 키로 옮기기 전 자리로 돌아가기 |
| `Ctrl+Alt+PgUp` / `Ctrl+Alt+PgDn` | 이전 / 다음 래더 블록(렁)의 처음으로 |
| `Space` / `Ctrl+Alt+F7` | 디바이스 찾기 창(접점·코일 목록, `Enter` 로 이동). `Ctrl+Alt+F7` 은 커서의 디바이스로 미리 걸러 둠 |
| `Ctrl+-` / `Ctrl++` | 커서가 있는 문장 그룹(머리글 렁 묶음) 접기 / 펴기. 접힌 머리글에서 `↑↓` 는 그룹을 펴지 않고 건너뜀 |
| `Ctrl+F5` | 코멘트 표시 단계 전환(끔 → 짧게 → 전체) |
| `Ctrl+;` | 문장 편집(이 앱에는 노트가 없어 렁 머리글 입력창이 열림) |
| `Ctrl+Alt+V` | 연속 붙여넣기: 복사한 접점을 디바이스 번호를 하나씩 올려 아래 행으로 붙임 |

### 선·행·열
| 키 | 동작 |
|---|---|
| `F9` / `Shift+F9` | 가로선 / 세로선 그리기 |
| `Ctrl+F9` / `Ctrl+F10` | 가로선 / 세로선 지우기 |
| `F10` / `Alt+F9` | 선 입력 모드(방향키로 선을 긋고 `F10`·`Esc` 로 끝) / 세로선 지우기 |
| `Ctrl+방향키` | 그 방향으로 선 긋기(이미 있으면 지우기). `Ctrl+Shift+←/→` 는 긋기만(옆 기호에 선 잇기). 접점 위에서 `Ctrl+↓/↑` 는 병렬 가지 입력 |
| `Ctrl+Insert` | 열 삽입: 커서 열 앞에 빈 열이 생겨 오른쪽이 모든 행(병렬 가지 포함)에서 한 칸씩 밀림. 빈 칸에 접점을 입력해 채움 |
| `Ctrl+Delete` | 열 삭제: `Ctrl+Insert` 로 끼운 빈 열을 모든 행에서 지우고 오른쪽을 당김(접점이 든 열은 지우지 않으니 `Delete` 로 하나씩 지움) |
| `Shift+Insert` / `Shift+Delete` | 렁(행) 삽입 / 삭제 |
